Run multiple AI coding agents in parallel

agnt seats a team of agents on one task. They work at the same time, share a task board, and you can talk to any of them mid-run.

Start a team

Run /team and pick a preset: squad, fullstack, research, audit or orchestra. Add a single agent with /spawn, or let the main agent delegate with /orch.

Stay in control

  • /agents lists agents and lets you chat with one; /focus switches to an agent's chat.
  • /board shows the shared task board; /map shows a live map of the orchestra.
  • /kill removes an agent; /roles lists available roles.
  • /worktree isolates work on its own git branch, and /undo or /rewind roll changes back.

Any model

Each team can run on Anthropic, OpenAI, Gemini and more, or on local models through Ollama. See local models.
