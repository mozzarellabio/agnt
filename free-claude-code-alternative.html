A free terminal coding agent that works with any model

agnt costs nothing. You bring your own API key, or run a local model, and keep the same agent, commands and workflow either way.

Models

Hosted: Anthropic, OpenAI, OpenRouter, Gemini, DeepSeek, Groq, xAI and Mistral. Local: Ollama and LM Studio. Any OpenAI-compatible endpoint can be added with /provider, and /fallback switches models when one errors or is rate-limited.

What stays the same

  • Modes: ask, auto, plan and free, with allow and deny rules.
  • Per-edit snapshots, /undo, /rewind and git worktrees.
  • Git and GitHub commands: /commit, /pr, /issue, /checks.
  • MCP servers, plugins and skills.
