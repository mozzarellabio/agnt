What is agnt?

agnt is an AI coding agent that runs in your terminal. It reads and edits your code, runs your checks, and can split a task across a team of agents working at the same time.

Which agnt is this?

This page is about agnt from mozzarellabio, a terminal coding agent. It is a different project from agnt-gg/agnt, which is an operating system for building and running AI agents and workflows.

What it does

  • Runs teams of agents in parallel with /team, each with a role such as architect, coder, reviewer or tester.
  • Works with Anthropic, OpenAI, OpenRouter, Gemini, DeepSeek, Groq, xAI and Mistral using your own keys, plus Ollama and LM Studio locally.
  • Batches tool calls, reads files in parallel, caches the stable part of the prompt and compacts long context.
  • Runs diagnostics after every edit and your typecheck or tests before it finishes.
  • Offers undo, rewind and git worktrees.
  • Supports MCP servers, plugins, skills and scheduled prompts.

Install

Linux: curl -fsSL https://raw.githubusercontent.com/mozzarellabio/agnt/main/install.sh | sh

Windows: irm https://raw.githubusercontent.com/mozzarellabio/agnt/main/install.ps1 | iex
